# Key Patterns (Quick Reference)

| Task | Pattern/File |
|---|---|
| API call | Extend HttpRequest → create Provider class |
| Global loading | handleLoading() from utils |
| Form submit | @primevue/forms <Form> + zodResolver |
| Pagination | usePagination() composable |
| Date format | useDayjs() from utils |
| Number format | filters/formatter from utils |
| Route auth | meta.auth: true |
| Toast | useToast() from plugins |
| Store access | useAuthStore(), useLoadingStore() |
| Drawer state | useAppDrawer() composable |
| Tab pages | useTabItems() composable |
| Copy to clipboard | useCopy() composable |
| Selection input | components/selection/ |
| Input validation | @keypress guards from plugins |
| Scroll to top | scrollToTop() from utils |
| Thai address | thai-address-universal package |
