# Utils

All utilities are pure, stateless, and live in `src/utils/`.

- **Formatting:** Formatter.ts
- **Loading:** HandleLoading.ts (global/local loading, error handling, toast)
- **Form:** HandleSubmit.ts (validation, scroll to error)
- **Storage:** Storage.ts (cookie/localStorage abstraction)
- **Scroll:** ScrollToTop.ts
