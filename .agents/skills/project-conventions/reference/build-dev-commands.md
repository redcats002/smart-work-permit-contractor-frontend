# Build & Dev Commands

```bash
bun run dev        # Dev server on 0.0.0.0:8080
bun run build      # Production build
bun run build:dev  # Development build
bun run build:stg  # Staging build
bun run preview    # Preview production build
bun run lint       # ESLint check
bun run test       # Vitest
```
