# PRE-002 — Print the loan agreement for a pre-contract

**Type:** feature · **Module:** pre-contract · **Status:** not-started

## Problem

A contract can be printed as `หนังสือสัญญากู้ยืมเงิน` via `ContractPrintPage`. A pre-contract
cannot. The print button on `PreContractDetailPage` was already wired to push
`{ name: 'PreContractPrintPage' }`, but that route was never created — so the button is
**currently broken in `dev`**.

## Tasks

Ordered. Each is independently verifiable; do not start the next until the previous passes lint + types.

### 1. Refactor `ContractPrintPage` into reusable components

- [ ] Create `src/pages/contract/components/print/LoanAgreementDocument.vue` holding the entire
      document body, driven by an `ILoanAgreementDocument` prop.
- [ ] Create `src/pages/contract/components/print/LoanAgreementSignatures.vue` for the
      single- vs multi-borrower signature layouts.
- [ ] Move the unscoped `.d-underline` / `.d-topic` styles and the Thai date helpers into
      `LoanAgreementDocument.vue`.
- [ ] Reduce `ContractPrintPage.vue` to: fetch → map to view-model → render.
- [ ] **Verify the existing contract print output is unchanged.** This step must be a visual no-op.

### 2. Widen the borrower model

- [ ] In `src/models/modules/pre-contract/Borrower.model.ts`, add to `IBorrowerCustomerList`:
      `birthDate?: string` and `mainAddress?: IAddressRequest`
      (import type from `@/models/request/AddressReq.model`).
- [ ] Both **optional** — the API does not return them yet. See
      [BACKEND-REQUEST.md](BACKEND-REQUEST.md). Optional means the UI compiles now, prints blanks
      at runtime, and starts printing real values when the API ships — no second FE change.

### 3. Add the pre-contract data source

- [ ] Create `useInitPreContractPrint.ts` using
      `PreContractService.getContractFindOne(id)` — declared as
      `const PreContractService: IPreContractProvider = new PreContractProvider()`.
- [ ] Map `IPreContractById` → `ILoanAgreementDocument`. Asset comes from `preAssets[0] ?? null`;
      no second API call is needed (unlike the contract page, which calls `getContractAssets`).
- [ ] Derive `firstInstallmentDate` = `contractedAt + 1 month` and `finalInstallmentDate` = `contractedAt + installmentCount months` via dayjs.

### 4. Create the page and route

- [ ] `src/pages/contract/pages/pre-contract-print/pages/PreContractPrintPage.vue`.
- [ ] Add the route to `src/router/modules/contract/index.ts` as `pre-contract/print/:id`,
      name `PreContractPrintPage`, `meta: { auth: true, layout: 'blank', title: 'พิมพ์สัญญา' }`
      — mirroring the existing `ContractPrintPage` route.
- [ ] Confirm navigation from `PreContractDetailPage` → print now resolves (it is already wired).

## Acceptance criteria

- [ ] Printed pre-contract is visually identical to a printed contract, with installment dates
      derived from `contractedAt` + `installmentCount`.
- [ ] The existing contract print page renders exactly as before the refactor.
- [ ] `borrowers` with 2+ entries still trigger `break-before-page` on the ข้อ 6 section.
- [ ] Print dialog auto-opens on mount, matching `ContractPrintPage` behavior.
- [ ] `./init.sh` passes.

## Pending backend (does not block implementation)

`อายุ` and the borrower address print blank until
`GET /api/v1/management/pre-contract/:id` returns `birthDate` and `mainAddress` on
`borrowers[].customer` — see [BACKEND-REQUEST.md](BACKEND-REQUEST.md). Both are optional on the
FE interface, so all four tasks ship independently and the fields light up on their own once the
API lands.

Falling back to the top-level `customer` object was considered and **rejected** — it would print
the primary customer's address against a co-borrower's name on a legal document.

## Out of scope

- Deriving installment dates from `contractedAt + installmentCount`. Implemented — both dates
  are computed client-side in `useInitPreContractPrint.ts` via dayjs.
- Guarantor (`ผู้ค้ำ`) signatures. The existing contract template does not render them and this
  ticket does not add them, even though `guarantors[]` exists on the response.
- Any change to the printed wording or layout.
