# PRE-004 — Extract asset detail formatting to utility function

**Type:** chore · **Module:** contract print · **Status:** done

## Problem

`LoanAgreementDocument.vue` lines 104-121 contain inline conditional rendering for asset
detail display:

```html
<template v-if="asset && isLand(asset.type)">
  <!-- land fields: aerialPhotoMapNo, landNo, surveyNo, subDistrict, district, province -->
</template>
<template v-else-if="asset && isVehicle(asset.type)">
  <!-- vehicle fields: brand, model, color, plateNo, province -->
</template>
<template v-else>
  <!-- blank underline fallback -->
</template>
```

This has two issues:
1. **Missing apartment type** — `APARTMENT_ROOM` assets fall through to the blank underline
2. **Template logic** — asset-type-specific field mapping belongs in a utility, not in the template

## Tasks

### 1. Create `formatAssetDetail` utility

Create `src/pages/contract/components/print/utils/formatAssetDetail.ts`:

```ts
import type { IPreAssetList } from '@/models/modules/pre-contract/PreAsset.model'
import { isLandAllAsset, isVehicleAsset, isApartmentAsset } from '@/enums/modules/asset/AssetType.enum'

export function formatAssetDetail (asset: IPreAssetList): string {
  const type = asset.type

  if (isLandAllAsset(type)) {
    const f = asset.realEstateForm
    return [
      asset.detail,
      `เลขที่ ${f?.aerialPhotoMapNo || '-'}`,
      `เลขที่ดิน ${f?.landNo || '-'}`,
      `หน้าสำรวจ ${f?.surveyNo || '-'}`,
      `ตำบล ${f?.subDistrict || '-'}`,
      `อำเภอ ${f?.district || '-'}`,
      `จังหวัด ${f?.province || '-'}`
    ].join(' ')
  }

  if (isVehicleAsset(type)) {
    const f = asset.vehicleForm
    return [
      asset.detail,
      `ยี่ห้อ ${f?.brand || '-'}`,
      `รุ่น ${f?.model || '-'}`,
      `สี ${f?.color || '-'}`,
      `หมายเลขทะเบียน ${f?.plateNo || '-'}`,
      `จังหวัด ${f?.province || '-'}`
    ].join(' ')
  }

  if (isApartmentAsset(type)) {
    const f = asset.apartmentCondoForm
    return [
      asset.detail,
      `โฉนดที่ดินเลขที่ ${f?.landNo || '-'}`,
      `ห้องชุดเลขที่ ${f?.unitNumber || '-'}`,
      `ชั้น ${f?.floorNumber || '-'}`,
      `อาคาร ${f?.buildingName || '-'}`,
      `ตำบล ${f?.subDistrict || '-'}`,
      `อำเภอ ${f?.district || '-'}`,
      `จังหวัด ${f?.province || '-'}`
    ].join(' ')
  }

  return asset.detail || ''
}
```
