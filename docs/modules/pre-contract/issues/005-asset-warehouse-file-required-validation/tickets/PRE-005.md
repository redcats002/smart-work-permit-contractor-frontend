# PRE-005 — Require `preAssets[i].files` in `AssetWarehouseForm`

**Type:** bug · **Module:** pre-contract · **Status:** done

## Problem

`src/pages/contract/pages/pre-contract-detail/components/make-contract/AssetWarehouseForm.vue`
should require at least one file for each asset before pre-make-contract confirmation, but empty
`preAssets[i].files` currently passes.

Current causes:

1. `files` is optional in `src/pages/contract/pages/pre-contract-detail/schema/make-contract.schema.ts`
2. the form receives an array but uses `zodResolver(PreAssetWarehouseSchema)`
3. the upload row uses `name="files"` instead of an indexed path, so the error cannot cleanly
   target a specific asset row
4. the manual validation function `manualValidateLocation()` doesn't validate files

## Scope

Only fix file-required validation for the make-contract asset warehouse step.

Do not:

- refactor unrelated pre-contract forms
- replace `UploadInput`
- change API payload structure
- add new dependencies

## Smallest safe implementation

### 1. Tighten the schema

In `make-contract.schema.ts`, make `files` required with a Thai error message:

```ts
files: z.array(schema.media).min(1, 'กรุณาแนบเอกสารหลักทรัพย์อย่างน้อย 1 ไฟล์')
```

### 2. Validate the actual form shape

In `AssetWarehouseForm.vue`, use `PreAssetWarehouseListSchema` for the resolver because
`<Form :initial-values="preAssets">` is validating the whole list, not one object.

### 3. Wire the indexed field path

Use the indexed file field path consistently:

- `LabelField :name="\`${i}.files\`"`
- pass the same indexed `name` into `UploadInput`

This gives the resolver and `scrollToFirstError()` a stable target for the failing asset row.

### 4. Show an invalid state without a big refactor

Use the `LabelField` slot's `invalid` value to highlight the upload box when files are missing.
Keep it minimal; a red border on the existing upload container is enough.

### 5. Update manual validation function

Update `manualValidateLocation()` to also validate `files`:

```ts
if (!asset.files || asset.files.length === 0) {
  errors.value.push({
    code: 'custom',
    path: `${index}.files`,
    message: `กรุณาแนบเอกสารหลักทรัพย์อย่างน้อย 1 ไฟล์สำหรับหลักทรัพย์ที่ ${index + 1}`
  })
}
```

This ensures manual validation matches schema requirements.

### 6. Leave one small runnable check

Add a focused Vitest schema test, for example:

- `src/tests/schema/make-contract.schema.test.ts`

Minimum assertions:

- empty `files` fails
- non-empty `files` passes
- existing `locationId` requirement still passes with valid input
